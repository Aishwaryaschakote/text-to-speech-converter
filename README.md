# Text-to-Speech Converter

This is a web-based Text-to-Speech Converter developed using HTML, CSS, and JavaScript.

The application converts user-entered text into speech using browser-supported speech synthesis APIs.

## Features

* Convert text into speech
* Easy-to-use interface
* Real-time voice output

## Technologies Used

* HTML
* CSS
* JavaScript
* Web Speech API

## My Learnings

This project helped me explore browser APIs and understand how web applications can interact with built-in system capabilities.
